# R3 — Evidence-backed answers and research continuity

R3 projects the existing browser_research_v2230 ledger into a readable answer on the Cloud and HomeServer Chat canvas. Each displayed claim retains source receipt labels, pinned source versions where available, evidence dates or an explicit unknown date, and the originally reviewed HTTPS URL where the Chat request recorded it. Claims without receipt-backed excerpts are excluded. Direct captured observations, inferred claims and unresolved conflicts remain distinct. A captured observation is not independently proven truth or guaranteed current information. Complete claim/citation blocks fit the existing report-summary limit; additional claims remain in the full canonical findings.

Explicitly saved Research project drafts can be recalled in later conversations. Current owner, Cloud lead namespace, Chat permission, project viewer access, nondeleted report, completed mission and existing website/runtime grants are checked at retrieval. HomeServer additionally checks the active local lead/conversation, pairing, session and Cloud/private scope before and after transport. Evidence is projected from the original ledger rather than copied into a new memory or history database. The report label makes clear this is captured evidence from a saved draft; edited report prose is not treated as newly captured source evidence.

The canvas Recall saved research action searches up to the 50 latest completed requests in the current owner/Cloud lead namespace and returns at most five accessible saved reports. Search matches meaningful terms in the question or captured answer. It never searches an external provider, reads a source, saves or restarts a run. The ordinary Cloud Chat owner Brain route recognizes explicit prior/saved research intent when Brain and Knowledge are enabled and returns cited captured findings. HomeServer owner Chat can supply bounded untrusted saved-source context to its selected model for that same explicit intent, respecting memory/knowledge/Cloud flags. Native context reserves budget and rechecks snapshot identities, project/site access, pairing and current privacy after model generation; changed authority discards the answer before assistant persistence. Model output itself is not certified as factual. Historical native Chat replies retain sanitized saved-report reference links on the canvas; opening them uses current Cloud report authorization.

Choose two saved reports explicitly to compare observed values by canonical claim key. New, different, same and not-reobserved observations are shown with the before/after citations. A new source version or evidence state is distinguished from an observed-value change. Different questions, source scopes, dates and extraction can cause differences; comparison does not prove a real-world change or treat omitted claims as false. Every new follow-up still uses R2 external-query consent, then R1 exact-source approval, leases and receipts. Comparisons never auto-run research.

Chrome 22.13.0 retains the existing identity key, worker and contract 1. Native schema stays 79. Connection recovery remains on hold.

## Automated acceptance gates

1. Claim-level citations, direct/inferred/conflict labels, unknown dates, complete bounded summaries and uncited-claim exclusion.
2. Durable saved recall with owner/lead/project/report/runtime/site revocation and relevant-query filtering.
3. Explicit two-report comparison with before/after receipts and truthful missing/changed-evidence semantics.
4. Real Cloud/native mobile canvas, safe text/links, locked comparison controls and revoked-result clearing; no search/read/save side effects from recall or comparison.
5. Native real Chat and pairing tests with controlled Cloud/model responses, bounded model context, post-answer snapshot/grant fences, no partial answer persistence and private/new-research isolation; retained R1/R2 and paired mission tests.
6. Immutable candidate and post-merge CI, Windows packaged browser/executable/installer and silent private-data upgrade preservation, unchanged merged trees and byte/digest-verified deploy archives.

The final score applies to these bounded automated gates. Authority/provider/model fixtures are identified in tests. Owner hardware, live pairing, unrestricted source discovery, custom plugins and live model accuracy are outside certification.
