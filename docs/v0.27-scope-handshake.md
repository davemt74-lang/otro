# HomeServer v0.27 — authenticated app-scope handshake

HomeServer remains authoritative for per-wrapper capability scopes introduced in v0.26.

The existing authenticated `GET /api/v1/tools` response now includes the normalized effective `app_scope` for the caller. This reuses the already allowlisted Remote Bridge `tools.list` path rather than adding a second identity or control operation to the bridge.

The scope is informational to the paired wrapper and cannot widen HomeServer permissions. HomeServer continues to enforce the same scope on Memory, Knowledge, Tools, Plugins, Agent context, and cloud-provider use.

The response is bearer-protected and the new regression verifies unauthenticated callers cannot read it.
