# A5C11 acceptance — Chat browser research and integration diagnostics

## Release gate

Merge only after every current-head workflow succeeds, including Windows packaged browser, installer, upgrade preservation and cross-system PHP-to-HomeServer acceptance. Deploy provenance must identify A5C11 and minimum browser-source schema 79. Release ZIPs must match merged source and include verified checksums.

## Score definition

A 10/10 release score means every requirement above has passing current-head automated evidence and matching merged deployment artifacts. A failure blocks that score and merge. This score does not certify the owner's installed network, custom plugins, active inference requests or physical hardware.

## Installed diagnostic

After deploying Cloud, upgrading HomeServer and reloading Chrome extension 22.10.0, run **Check integration** on the Chat canvas or **Settings → Check Cloud and HomeServer integration**. Report each blocked/not-verified check separately. Repository fixtures cannot establish the current health of the owner's installation. This diagnostic does not perform repairs, browser launching, inference requests or physical device commands.
