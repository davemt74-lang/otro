# Chat multi-source research — Phase 2 / R1

Cloud and HomeServer Chat expose **Chrome research** alongside the existing modes. Choose an existing active Chrome runtime with Browser Research and multi-site website grants; include one public HTTPS read URL per website, up to five. Review the exact source plan before starting. Chrome uses dedicated inactive tabs in the existing browser profile and the canonical research extraction/evidence ledger. Read steps are sequential and bounded; this phase does not add independent Chrome login sessions, a new search engine or new specialist scheduling.

The request queue stores reviewed scope and canonical mission references only. Evidence, supported claims, source versions, conflicts and report drafts remain in the existing Chrome/Cloud Research system. Known source versions are pinned; fingerprint-only evidence is clearly disclosed. Public proposed URLs are retained as reviewed scope; captured page text and analyzed raw URLs remain ephemeral.

HomeServer sends only the explicit user research request and identifiers through its current paired Cloud session, checks conversation Cloud privacy and current pairing/app grants before and after transport, and stores no second evidence copy. Chrome owns an exclusive expiring lease; each source analysis verifies the exact URL and current lease before inference and again under transaction lock before saving evidence. Completed receipts are reused after lost acknowledgements. Interrupted work requires review; alarms never request website permissions. Redirects outside the exact reviewed URL stop for review. Reports are saved only as drafts after explicit confirmation and current project write authority.
